# Contributing to Hisab

Thank you for your interest in reviewing or contributing to **Hisab**!

This repository serves primarily as a **Portfolio & Showcase Project** developed by **Samir Khan** ([@samirkhan95](https://github.com/samirkhan95)).

## 🐛 Reporting Issues & Feedback

If you discover any bugs, UI glitches, or have suggestions for architectural improvements:
1. Open a new issue in the [GitHub Issues](https://github.com/samirkhan95/hisab/issues) tab.
2. Provide a clear description of the behavior and steps to reproduce.

## 🔀 Pull Requests

Contributions for bug fixes, code optimizations, or documentation enhancements are welcome:
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Ensure your code conforms to standard Flutter lints (`flutter analyze`).
4. Commit your changes with descriptive messages (`git commit -m 'Add amazing feature'`).
5. Push to your branch and open a Pull Request against `main`.

Thank you for exploring **Hisab**!
